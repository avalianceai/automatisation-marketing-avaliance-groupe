Comment ça marche

Trois endroits. Vous n'en touchez que deux : le serveur, vous ne le voyez jamais.

Le serveurUn robot d'Avaliance qui lit des sites d'actualité toute la journée et range les sujets dans l'armoire. Il tourne seul. Seul Avaliance s'en occupe.
GitHub, l'armoireUn placard en ligne, privé. Le robot y dépose les sujets ; vous y rangez votre voix, votre charte, vos textes. Votre compte GitHub en a déjà la clé.
Votre PCClaude et les agents. Ils prennent les sujets dans l'armoire et vous proposent un sujet, un texte, un visuel. Vous choisissez, puis vous publiez.

Les étapes

Une seule fois, environ 25 minutes. Les étapes 1 à 3 se tapent dans PowerShell (menu Démarrer, taper « PowerShell »). Chaque commande a un bouton Copier. Cochez chaque étape faite.

0 étape faite

1. Installer Git

PowerShell · 3 min

Pourquoi : Git est l'outil qui ouvre l'armoire GitHub depuis votre PC : il ramène les sujets et y range votre travail.

winget install --id Git.Git -e --source winget

Fermez PowerShell, rouvrez-le, puis vérifiez :

git --version

Résultat attendu : git version 2.x

2. Installer Google Chrome

PowerShell · 3 min

Pourquoi : Les agents dessinent le visuel en page web, puis Chrome le transforme en image à publier.

Chrome sert à fabriquer l'image du visuel. Si Chrome est déjà installé, passez à l'étape suivante.

winget install --id Google.Chrome -e --source winget

3. Connecter GitHub et créer le dossier de travail

PowerShell · 3 min

Pourquoi : Cette commande copie l'armoire GitHub sur votre PC, dans Documents\Avaliance Marketing. C'est votre dossier de travail, dès maintenant et pour toujours. Elle enregistre aussi votre connexion GitHub, que Claude réutilisera pour installer les agents.

Une fenêtre GitHub s'ouvre : connectez-vous avec votre compte GitHub.

git clone https://github.com/avalianceai/ava-marketing.git "$HOME\Documents\Avaliance Marketing"

Résultat attendu : Cloning into ... done. Le dossier Avaliance Marketing apparaît dans Documents.

Puis :

setx CLAUDE_CODE_PLUGIN_PREFER_HTTPS 1

Résultat attendu : SUCCESS: Specified value was saved.

4. Installer Claude et ouvrir votre session de travail

navigateur puis Claude · 7 min

Pourquoi : Claude est l'application dans laquelle vous travaillerez. On y parle dans une session : une conversation ouverte sur un dossier de votre PC. Les agents travaillent dans ce dossier : c'est là qu'ils trouvent les chartes et les sujets. L'onglet Code est celui qui sait utiliser les agents.

Téléchargez et installez Claude depuis cette adresse, puis connectez-vous avec votre compte Claude Pro.

https://claude.com/download
Ouvrir la session de travail, pas à pas :
  1. En haut de la fenêtre Claude, cliquez sur l'onglet Code.
  2. Cliquez sur Nouvelle session.
  3. Claude demande un dossier : choisissez Documents, puis Avaliance Marketing (créé à l'étape 3).
  4. En bas de l'écran apparaît la zone où l'on écrit : c'est là que vous taperez toutes les commandes, aujourd'hui et chaque jour.
Documents\Avaliance Marketing

5. Installer les agents

Claude, onglet Code · 3 min

Pourquoi : On installe le paquet d'agents d'Avaliance : le rédacteur en chef, le rédacteur, le maquettiste, le contrôleur, et les commandes. Ils ne contiennent aucune société : ce sont des méthodes. Ils s'installent une fois pour toutes dans Claude, et serviront dans toutes vos sessions.

Où taper : dans la session ouverte à l'étape 4 (sur Documents\Avaliance Marketing), dans la zone d'écriture en bas. Collez une commande, appuyez sur Entrée, attendez la réponse, puis passez à la suivante.
/plugin marketplace add avalianceai/automatisation-marketing-avaliance-plugin

Résultat attendu : Successfully added marketplace: avaliance-marketing

/plugin install automatisation-marketing-avaliance@avaliance-marketing

Résultat attendu : le plugin est indiqué comme installé.

/reload-plugins

Enfin, une seule fois : activez la mise à jour automatique des agents.

/plugin

Dans le menu qui s'ouvre : Marketplaces, puis avaliance-marketing, puis Enable auto-update. Ensuite, vous n'aurez plus jamais à mettre les agents à jour vous-même.

6. Préparer le poste

Claude, même session · 5 min

Pourquoi : Les agents sont installés. Cette commande vérifie que tout répond : l'accès à l'armoire, le dossier de travail, la fabrication des visuels.

Où taper : toujours dans la même session. Quand Claude demande d'autoriser la séance à écrire, répondez Oui.
/installer

Résultat attendu : prêt : tapez /societe docdialy pour voir la société, puis /publier docdialy

7. Première société, première publication

Claude, même session · 40 min

Pourquoi : Tout est installé. On regarde d'abord ce qu'on sait de Docdialy, puis on lance la première séance de publication.

Où taper : toujours dans la même session, ouverte sur Documents\Avaliance Marketing. Chaque matin ensuite : ouvrez Claude, onglet Code, et reprenez une session sur ce dossier.
/societe docdialy
/publier docdialy
