Le poste du service marketing

Automatisation du service marketing Avaliance. Un seul document : d'abord l'installation, une fois, puis le guide de tous les jours.

Vous tapez une commande dans Claude. Une équipe d'agents fait le travail : elle trie l'actualité, écrit, dessine, vérifie. Elle s'arrête pour vous demander à chaque étape importante. Vous gardez toujours la main, et c'est vous qui publiez.

Comment ça marche

Trois endroits. Vous n'en touchez que deux : le serveur, vous ne le voyez jamais.

Le serveurUn robot d'Avaliance qui lit des sites d'actualité toute la journée et range les sujets dans l'armoire. Il tourne seul. Seul Avaliance s'en occupe.
GitHub, l'armoireUn placard en ligne, privé. Le robot y dépose les sujets ; vous y rangez votre voix, votre charte, vos textes. Votre compte GitHub en a déjà la clé.
Son PCClaude et les agents. Ils prennent les sujets dans l'armoire et vous proposent un sujet, un texte, un visuel. Vous choisissez, puis vous publiez.

A. Installer le poste

Une seule fois, environ 25 minutes. Les étapes 1 à 3 se tapent dans PowerShell (menu Démarrer, taper « PowerShell »). Chaque commande a un bouton Copier. Cochez chaque étape faite.

0 étape faite

1. Installer Git

PowerShell · 3 min

Pourquoi : Git est l'outil qui ouvre l'armoire GitHub depuis votre PC : il ramène les sujets et y range votre travail.

winget install --id Git.Git -e --source winget

Fermez PowerShell, rouvrez-le, puis vérifiez :

git --version

Résultat attendu : git version 2.x

2. Installer Google Chrome

PowerShell · 3 min

Pourquoi : Les agents dessinent le visuel en page web, puis Chrome le transforme en image à publier.

Chrome sert à fabriquer l'image du visuel. Si Chrome est déjà installé, passez à l'étape suivante.

winget install --id Google.Chrome -e --source winget

3. Connecter GitHub, une fois pour toutes

PowerShell · 3 min

Pourquoi : Claude installe les agents depuis GitHub sans pouvoir afficher de fenêtre de connexion. On enregistre donc la connexion une fois, ici, pour qu'il ne la redemande plus.

Une fenêtre GitHub s'ouvre : connectez-vous avec votre compte GitHub.

git ls-remote https://github.com/avalianceai/automatisation-marketing-avaliance-plugin.git HEAD

Résultat attendu : une ligne de 40 caractères suivie de HEAD.

Puis :

setx CLAUDE_CODE_PLUGIN_PREFER_HTTPS 1

Résultat attendu : SUCCESS: Specified value was saved.

4. Installer Claude et ouvrir une première session

navigateur puis Claude · 7 min

Pourquoi : Claude est l'application dans laquelle vous travaillerez. On y parle dans une session : une conversation ouverte sur un dossier de votre PC. L'onglet Code est celui qui sait utiliser les agents.

Téléchargez et installez Claude depuis cette adresse, puis connectez-vous avec votre compte Claude Pro.

https://claude.com/download
Ouvrir une session, pas à pas :
  1. En haut de la fenêtre Claude, cliquez sur l'onglet Code.
  2. Cliquez sur Nouvelle session.
  3. Claude demande un dossier : choisissez le Bureau (pour l'installation seulement).
  4. En bas de l'écran apparaît la zone où l'on écrit : c'est là que vous taperez les commandes de l'étape suivante.

5. Installer les agents

Claude, onglet Code · 3 min

Pourquoi : On installe le paquet d'agents d'Avaliance : le rédacteur en chef, le rédacteur, le maquettiste, le contrôleur, et les commandes. Ils ne contiennent aucune société : ce sont des méthodes. Ils s'installent une fois pour toutes dans Claude, et serviront dans toutes vos sessions.

Où taper : dans la session ouverte à l'étape 4 (sur le Bureau), dans la zone d'écriture en bas. Collez une commande, appuyez sur Entrée, attendez la réponse, puis passez à la suivante.
/plugin marketplace add avalianceai/automatisation-marketing-avaliance-plugin

Résultat attendu : Successfully added marketplace: avaliance-marketing

/plugin install automatisation-marketing-avaliance@avaliance-marketing

Résultat attendu : le plugin est indiqué comme installé.

/reload-plugins

6. Préparer le poste

Claude, même session · 5 min

Pourquoi : Les agents sont là, mais pas encore les dossiers des sociétés. Cette commande copie l'armoire sur votre PC, dans Documents\Avaliance Marketing, et vérifie que tout répond, visuel compris.

Où taper : toujours dans la même session (celle du Bureau). Quand Claude demande d'autoriser la séance à écrire, répondez Oui.
/installer

Résultat attendu : prêt : tapez /societe docdialy

7. Ouvrir votre session de travail, celle de tous les jours

Claude · 1 min

Pourquoi : Les agents travaillent dans le dossier sur lequel la session est ouverte. Ce dossier est votre copie de l'armoire : c'est là qu'ils trouvent les chartes et les sujets. La session du Bureau ne servait qu'à installer : vous pouvez la fermer.

Ouvrir la session de travail :
  1. Onglet Code, puis Nouvelle session.
  2. Comme dossier, choisissez Documents, puis Avaliance Marketing (le chemin est ci-dessous).
  3. Tapez /societe docdialy dans la zone d'écriture : c'est parti.
Documents\Avaliance Marketing

Chaque matin ensuite : ouvrez Claude, onglet Code, et reprenez une session sur ce dossier. Toutes les commandes du guide se tapent là.

B. Le guide de tous les jours

Ce que vous pouvez demander à Claude, avec quelle commande, et ce qui se passe ensuite.

B1Une journée type

Comptez de 20 à 40 minutes par publication.

Où taper toutes les commandes de ce guide : dans Claude, onglet Code, dans une session ouverte sur le dossier Documents\Avaliance Marketing (étape 7). Une session ouverte ailleurs ne trouvera pas vos sociétés.
/societe docdialy
Claude vous demandeVous pouvez répondre
1Quel sujet publie-t-on aujourd'hui ?un des sujets proposés, ou « refais le tri, je veux plutôt… »
2Quel texte garde-t-on ?la version A, B ou C, ou « reprends-le, plus court », « change le début »…
3Le visuel convient-il ?oui, un autre modèle, une retouche, ou « sans visuel »

À la fin, un dossier s'ouvre avec le texte à copier, l'image à joindre, et une fiche qui dit quoi mettre où. Vous publiez vous-même sur LinkedIn, Instagram ou Facebook. Vous pouvez répondre à Claude en français, normalement, à tout moment.

B2Toutes les commandes

Une commande commence par une barre oblique. Remplacez docdialy par le nom de la société sur laquelle vous travaillez.

Publier : la séance du jour

tous les jours
/societe docdialy

Ce qu'elle fait : récupère les sujets trouvés par le robot, les fait trier, écrire, vérifier, puis habiller, en s'arrêtant trois fois pour vous demander.

Ce que vous obtenez : un dossier « prêt » avec le texte par réseau et l'image.

Tester un site avant de le surveiller

quand vous trouvez un site
/tester-source https://www.dsih.fr docdialy

Ce qu'elle fait : vérifie en une minute si le robot pourra lire ce site, et s'il parle vraiment de votre métier. Rien n'est ajouté.

Ce que vous obtenez : vert (bon, on peut l'ajouter), orange (possible, mais le site publie peu ou n'a pas de flux), rouge (le site bloque les robots, ou il est hors sujet), avec la raison.

Changer ce que le robot surveille

quand vous voulez
/sources docdialy

Ce qu'elle fait : vous dites en français ce que vous voulez : « ajoute le site de l'ANAM », « retire Ouest-France », « ramène aussi les articles sur l'assurance maladie ». Le site est testé d'abord, puis inscrit.

Ce que vous obtenez : le robot en tient compte au plus tard 20 minutes après. Les nouveaux sujets arrivent dans votre prochaine séance.

Définir ou corriger la voix d'une société

au début, puis de temps en temps
/automatisation-marketing-avaliance:ligne-editoriale docdialy

Ce qu'elle fait : un entretien. L'agent vous montre ce qui existe déjà et vous pose des questions : à qui parle-t-on, sur quel ton, ce qu'on dit, ce qu'on ne dit jamais, les faits qu'on a le droit de citer, les sujets à surveiller.

Ce que vous obtenez : la ligne éditoriale de la société, que tous les agents suivent ensuite. Tapez bien la commande en entier : la forme courte appelle un autre outil.

Définir ou corriger la charte graphique

au début, puis de temps en temps
/charte docdialy

Ce qu'elle fait : couleurs, polices, logo, formats par réseau. L'agent mesure que les textes restent lisibles sur chaque couleur.

Ce que vous obtenez : la charte et les modèles de visuels de la société.

Ajouter une nouvelle société

rarement
/nouvelle-societe shifaa

Ce qu'elle fait : enchaîne la ligne éditoriale puis la charte graphique pour une société qui n'existe pas encore.

Ce que vous obtenez : son dossier complet. Dès le lendemain, vous pouvez taper /societe shifaa.

Réparer le poste

si quelque chose ne marche plus
/installer

Ce qu'elle fait : revérifie tout (accès, dossiers, fabrication des images) et répare ce qui manque. Elle ne supprime rien.

Recevoir les améliorations

quand Avaliance vous le dit
/plugin marketplace update avaliance-marketing

Ce qu'elle fait : met à jour les agents. Vos sociétés et vos publications ne sont pas touchées.

B3L'équipe d'agents

Vous ne les appelez jamais directement : les commandes le font pour vous. Ils sont les mêmes pour toutes les sociétés. Seul le dossier de la société change.

Prépare une sociétéLigne éditorialeÉcrit la voix, les interdits, les faits citables et les sites à surveiller.
Prépare une sociétéCharte graphiqueÉcrit les couleurs, les polices, le logo et les modèles de visuels.
Chaque jourRédacteur en chefLit les sujets du robot, en garde 3 à 5, propose un angle pour chacun, jette le reste.
Chaque jourRédacteurÉcrit 2 ou 3 versions du texte, dans la voix de la société, avec ses seuls faits vérifiés.
Chaque jourDirecteur de publicationRelit avant vous : refuse tout chiffre non prouvé, tout mot interdit, tout conseil médical.
Chaque jourMaquettisteAprès votre choix de texte, l'adapte à chaque réseau et fabrique l'image.

B4Le robot de veille

Un robot d'Avaliance lit des sites d'actualité jour et nuit, pour chaque société, et range les sujets dans un espace partagé en ligne (GitHub). Vous n'avez rien à faire avec lui : votre séance y prend les sujets, et /sources lui dit quoi lire. Vous n'avez aucun serveur à ouvrir.

B5Où sont vos fichiers

Tout est dans Documents\Avaliance Marketing. Vous n'avez pas besoin d'y aller : Claude vous ouvre le bon dossier. Mais si vous cherchez quelque chose :

DossierCe qu'il contient
missions\docdialy\pret\vos publications prêtes : un dossier par publication, avec le texte à copier, l'image et la fiche « à publier »
missions\docdialy\1-sujets\les sujets trouvés par le robot, un fichier par jour
reference\docdialy\la ligne éditoriale et la charte de la société
gabarits\docdialy\les modèles de visuels

B6Les règles que les agents respectent toujours

1
Pas de preuve, pas de publication. Aucun chiffre, aucun nom de client, aucune affirmation qui ne figure pas dans les faits vérifiés de la société. Un trou est signalé, jamais comblé au hasard.
2
Santé : jamais de conseil médical. On parle du logiciel, de l'organisation, des données. Jamais du patient, du soin ou du diagnostic.
3
Aucun émoji dans ce qui porte le nom d'une société.
4
Rien ne part sans vous. Les agents proposent, vous choisissez, vous publiez. Ils ne publient jamais et ne répondent à aucun commentaire.
5
Tout est gardé. Chaque séance range son travail dans l'espace partagé. Si vous fermez Claude au milieu, la séance suivante reprend où elle s'était arrêtée.
